# 👑 БОГИНЯ СОЦСЕТЕЙ — METAIMPERIYA

Практическое руководство для тех, кто хочет научиться пользоваться интернетом, социальными сетями и продвигать себя или свой бизнес.

## Структура

- 30 глав
- Практические задания
- Чек-листы
- Интерактив: поиск, тёмная/светлая тема, прогресс-бар чтения

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript

## Запуск

Открой `index.html` в браузере.
